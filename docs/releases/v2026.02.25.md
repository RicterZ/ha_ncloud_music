# 2026.02.25 - 外部接管与播放状态保护

本版本增加和完善了代理播放器的 stop 功能，同时聚焦“共享底层播放器”的兼容性问题（TTS / 自动化 / 云音乐混用），重点优化代理播放器的状态一致性，降低误判“幽灵播放”带来的异常恢复。

核心修复

- 外部接管识别与保护  
  当底层播放器被 TTS 或自动化临时接管时，代理播放器会识别为“外部接管”，并临时关闭幽灵播放的恢复，避免误拉起历史歌曲。

- seek 兼容性修复  
  针对不支持 `media_seek` 的设备（部分音箱），新增能力检测与降级逻辑，自动跳过 seek 调用，减少无效报错。

功能更新

- 新增 `ha_ncloud_music.stop` 服务  
  可在自动化中直接停止当前云音乐播放，便于场景联动和语音控制。

- 播放恢复逻辑优化  
  在外部播放结束后，代理播放器会根据接管前状态恢复。

体验优化

- 状态同步稳定性提升  
  统一了关键播放服务的调用时序，减少“前端显示状态”和“底层真实状态”短时不一致导致的界面抖动。

升级说明

- 升级后建议重启 Home Assistant。
